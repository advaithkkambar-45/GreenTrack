About GreenTrack

A digital companion for community tree plantation activities—helping a team record planted trees, follow their condition and maintain a simple history of growth.

🌱
01 · PROJECT DETAILS

What is GreenTrack?

GreenTrack is a software-based Tree Plantation Management System developed to support afforestation and tree-care activities in a community, campus or other selected location. It provides a central place to register each planted tree and maintain information such as its species, planting location, planting date, responsible person and current condition. Follow-up entries can be used to record observations and height measurements over time.

The purpose is to make plantation records easier to organise and review. Instead of relying only on handwritten notes, users can use the dashboard to view registered trees, search records, update details and export the records as a CSV file.

03 · HOW IT WORKS

Simple project workflow

  1. Register a treeEnter its species, location, planting date and optional photo.
  2. Update its conditionChoose a status and add notes when the tree is inspected or maintained.
  3. Record growthAdd a dated log with height and observations when information is available.
  4. Review and exportUse the dashboard to search records and download a CSV report.
04 · TECHNOLOGY

Tools and technologies

PythonFlaskSQLiteHTMLCSS

The application runs locally in a web browser. SQLite stores the records on the computer where the application is running.

05 · PROJECT SCOPE

What this version includes

  • Tree registration, viewing, editing and deletion
  • Optional tree photo upload
  • Tree status and maintenance notes
  • Growth and condition history
  • Dashboard summary, search and status filtering
  • CSV export of tree records
Current limitations: This is a local software prototype. It does not automatically detect tree health, verify survival rates, provide live GPS tracking, use sensors or synchronise data to a cloud server. The dashboard figures depend on the records entered by users.
